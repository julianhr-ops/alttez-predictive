Evaluation method

The project is built around the evaluation harness. A model is trusted only after it has been scored the same way as its competitors on the same games.

Walk-forward

Every test period is predicted only from data that came before it. Hyperparameters, calibrators and blend weights are fitted on earlier seasons or years, never on the period being scored. Ratings score a game from the state before its date, so a prediction cannot see its own result.

Baselines on identical games

Uniform, base rate, plain Elo and the NBA closing line are scored on exactly the same matches as the model. Beating a coin flip is not reported as a win.

Paired bootstrap

For each comparison the harness resamples per-game loss differences, in blocks of game dates when games share a day, and reports a 95% interval. A difference counts only when the interval excludes 0.

Negative results are kept

  • The legacy Poisson soccer model is worse than an Elo-only baseline.
  • NBA Elo does not beat the market closing line in any test season.
  • A blend of Elo and the market line only reproduces the line.
  • Temperature calibration of the Poisson model changes nothing measurable.

Leakage and duplication fixes

  • A calibration fitted on one shape of data and applied to another.
  • Duplicate prediction rows that inflated the learning data.
  • An Elo K factor that treated qualifiers as finals.
  • A model registry failure that silently served the fallback.

Each fix has a test. NBA predictions are keyed on game, model version and served model. They are written while the game is scheduled and never rewritten after tip-off, so the live scoreboard cannot be edited after the fact.
